# One company logo

OpsDevCode has **one logo**. Product marks are not company logos. Share banners
are not logos. The retired “O / terminal” rasters are not logos.

## The drawing

Four open L-corners on a 32-unit grid, 1.5 stroke, square caps, empty center.
That aperture **is** the company mark. The lockup is the mark plus the word
**OpsDevCode** in IBM Plex Sans.

| File                                  | Use                                                         |
| ------------------------------------- | ----------------------------------------------------------- |
| `public/brand/mark-opsdevcode.svg`    | Mark only (transparent). Header/footer via `BrandMark`.     |
| `public/brand/lockup-opsdevcode.svg`  | Mark + word. Wide placements, print, slides.                |
| `public/brand/favicon-opsdevcode.svg` | Same mark on paper. Favicon, app icon, GitHub org avatar.   |
| `public/brand/og-opsdevcode.svg`      | Same lockup at 1200×630. Unfurl art, not a second identity. |

Do not invent a fifth drawing for GitHub, LinkedIn, Calendly, or Netlify.

## What sits next to it

- **Products** use their own section-cut marks (Repave, Overpass, Toll, Dispatch)
  and the endorsement `{Product} — by OpsDevCode`.
- **Convergence** keeps its own identity. It is not an OpsDevCode product.

## GitHub org

Set the organization avatar to `favicon-opsdevcode.svg` (export a PNG if GitHub
requires raster). Do not use `public/assets/opsdevco-logo-o-*.png` or the
profile banner as the avatar.
